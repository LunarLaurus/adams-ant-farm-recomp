# Third-party dependencies

Every project this repository vendors or builds against, and the license each one is actually
distributed under. This project's own Apache-2.0 license (`LICENSE`) covers only this
repository's own original code - it does not relicense anything listed here. See `LEGAL.md` for
how these interact (in particular: linking a GPL-3.0 dependency into a distributed binary has
real consequences for the combined work, not just this repo's own files).

For specific code ported or adapted from one of these projects (as opposed to general use as a
build dependency), see `NOTICES.md` - that file carries the per-port attribution these licenses
require; this file is the inventory of what's vendored and under what terms.
